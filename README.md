# Color Changer

Checkpoint JavaScript : une boite qui change de couleur quand on clique sur le bouton.

## Fichiers

- `index.html` : la page (titre, boite, bouton)
- `style.css` : le style
- `script.js` : le code JavaScript

## Tester

Ouvrir `index.html` dans le navigateur et cliquer sur **Change Color**.
La couleur de la boite change a chaque clic.
